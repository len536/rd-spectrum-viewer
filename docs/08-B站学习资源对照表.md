## 0. 先看这一条：最小学习路径（按顺序，别跳）

你现在卡在「看不懂代码」，根子不是项目难，是 **Python 基础没学完**。
直接学 PySide6 你会更晕——就像没学过加减法就直接学解方程。

| 顺序 | 学什么 | 用什么课 | 看到什么程度就往下走 |
|---|---|---|---|
| ① | **Python 基础**（变量 / if / for / 函数 / 列表 / 类） | 林粒粒 3h 速通（见 §1） | 能自己写出「读文件→打印」几行代码 |
| ② | **NumPy** | 莫凡 NumPy（见 §2） | 懂 ndarray / shape / 切片 / 广播 |
| ③ | **Matplotlib imshow** | 莫凡 Matplotlib（见 §3） | 懂 cmap / vmin / colorbar（你已会一半） |
| ④ | **PySide6 信号槽 + 布局** | 白月黑羽（见 §4） | 能讲 `connect` 和 `QVBoxLayout` |
| ⑤ | **QThread 多线程** | 11 分钟短课（见 §5） | 懂「工作线程不碰 UI」 |
| ⑥ | Git / 打包 | 10 分钟+18 分钟短课（见 §6/§7） | 能自己 push、能看懂打包报错 |

> ① 是硬前提。②–⑤ 可以直接对着**我们项目已有的代码**学：看一集，回来看一眼代码里对应的那行，效果最好。

## 9. 怎么用这份表（重要）

1. **一次只学一科**，按 §0 的顺序走。别同时开三个视频。
2. **看一集，回来看一眼代码**——找到视频里讲的东西在我们项目哪一行。这是「看懂」的关键动作，光看视频不动手等于没学。
3. **看不懂的词查 `docs/06-代码词词典.md`**，不用回头翻视频。
4. **看完一科，回来给自己打 ✅**（在 `docs/00-知识点地图.md` 台账里）。判定还是那三条：能讲、能改、能预测。
5. **别追求刷完**。你现在的目标不是「学完 Python」，是「看得懂这个项目、组会答得上来」。
