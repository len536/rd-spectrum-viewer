## 二、6 个问题，以及"为什么必须问"

| # | 问题 | 为什么必须问 | 不知道会怎样 |
|---|---|---|---|
| 1 | **文件格式**：txt / csv / npy / mat / 二进制 / Socket | 决定用 `np.loadtxt` / `np.load` / `scipy.io.loadmat` / `socket`，甚至要不要装 SciPy | 读取代码整个写法不一样，白写 |
| 2 | **维度 + 两维含义**：shape 是多少，哪维距离、哪维多普勒 | 决定要不要**转置**、坐标轴标签写什么 | 图会横竖颠倒，距离和速度对不上 —— 组会一眼被看穿 |
| 3 | **数值单位**：线性功率 / dB / 复数 I/Q | 决定要不要 `abs()`、`10*log10()` | 颜色全糊成一片，或者量级错得离谱 |
| 4 | **标定向量**：距离(m)、速度(m/s)、PRF、波长 | 决定坐标轴用 bin 索引还是 `extent` 换物理量 | 只能标"第几个通道"，专业度不够 |
| 5 | **更新方式**：单文件 / 实时流 / 频率 | 决定要不要 `QThread`、定时器、双缓冲 | 实时数据下界面直接卡死 |
| 6 | **样例 + MATLAB 截图** | 「接近 MATLAB」的**验收基准**，配色/色表/colorbar/坐标范围全靠它对齐 | 只能凭猜，老师一句"不像"就打回 |

> 附加：单帧数据量（MB）→ 决定要不要分块读取 / 降采样（阶段 4）。

## 四、拿到真实数据后改哪里

**只改 `load_rd()` 一个函数**，保证返回 `shape=(距离门, 多普勒通道)` 的二维 float 数组（单位 dB）。其余代码一律不动。

四种常见格式的模板（阶段 4 会正式实现，先眼熟）：

```python
# ① 纯文本 / csv，每行一个距离门，逗号分隔
rd = np.loadtxt(path, delimiter=",")

# ② NumPy 二进制
rd = np.load(path)

# ③ MATLAB .mat（需 scipy，阶段 4 才装）
from scipy.io import loadmat
rd = loadmat(path)["rd"]        # 键名要问同学，MATLAB 里变量名是什么

# ④ 复数 I/Q → 功率 → dB
rd = 10 * np.log10(np.abs(iq) ** 2 + 1e-12)   # +1e-12 防止 log10(0)

# ⑤ 如果两维是反的
rd = rd.T
```

> 不管哪种，最后都 `assert rd.ndim == 2`，并在 `load_rd()` 里打印 shape 和范围 —— 这是**最快发现接口对不上**的办法。
