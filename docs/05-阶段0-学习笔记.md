## 1. 技术栈是什么（盖楼类比）

**栈（stack）= 一堆东西叠起来。技术栈 = 做这个软件要用的一整套技术，从地基到房顶一层层叠。**

| 层 | 选型 | 盖楼类比 | 为什么（要能讲出来） |
|---|---|---|---|
| 语言层（地基） | Python 3.13 | 施工用的工具 | 老师给定；科学计算生态成熟；能打包成 exe |
| 数据层（砖） | NumPy | 盖楼的基本材料 | RD 谱本质就是一张二维数字表 |
| 绘图层（装修） | Matplotlib | 把房子弄好看 | 能精调色表/colorbar，又能嵌 Qt 窗口，最接近 MATLAB |
| 界面层（门窗） | PySide6 | 给人进出的界面 | 按钮、选文件、布局；官方 + LGPL，见第 3 节 |
| 交付层（交房） | PyInstaller（阶段 5） | 打包成别人能直接住的成品 | 老师电脑不用装 Python |

**少一层楼都不完整——这就是"技术栈"，不是单个工具，是全套搭配。**

## 2. 「定」技术栈 和「选型」在干嘛

- **定** = 开工前拍板、写死不再改。为什么提前定？**中途换框架 = 推倒重来**。界面写一半才发现该用 PySide6，前面的 PyQt5 代码全得重写。
- **选型** = 在几个备选里挑一个，还**必须说出理由**。老师问「为什么用 X」，考的是理由，不是背名字。

## 3. PySide6 拆词 + 选型三条

`PySide6` = **Py**（Python）+ **Side**（Qt 官方绑定的名字）+ **6**（Qt 第 6 版）。
人话：**Qt 官方出的、让你用 Python 搭界面的工具箱**。代码里所有 `Q` 开头的类（`QApplication`/`QPushButton`…）都来自它。

- **Qt** 是什么？一个用 C++ 写好的"界面积木库"——窗口、按钮、布局都现成。类比乐高积木。
- **绑定 binding** 是什么？把 C++ 库接到 Python 上的转接头，让你用 Python 指挥积木。PySide6 = 官方做的转接头；PyQt5 = 第三方做的另一个转接头。

**为什么选 PySide6，不选 PyQt5（三条，必背）：**

| # | 理由 | 大白话 |
|---|---|---|
| 1 | 官方 | PySide6 是 Qt 公司亲儿子、官方维护；PyQt5 是第三方 Riverbank 做的 |
| 2 | 许可证（最硬） | PySide6 用 **LGPL**：交付/商用可闭源，不用公开源码。PyQt5 默认 **GPL**：有传染性，用了它你的软件也得开源；想闭源要付费买商业许可。老师将来要交成品，不能埋这个雷 |
| 3 | 教程通用 + 团队统一 | 两者 API 几乎一样，PyQt5 教程能直接套；且团队 UAV 地面站也定 PySide6，一套技能两处用 |

**许可证类比**：LGPL = "免费食材，你做成的菜配方是你的，能拿去卖"；GPL = "用了这调料，整道菜配方必须公开给所有人"。

**「为什么不用」三连（老师爱追问的备选方案）：**

- 不用 PyQt5：许可证风险 + 非官方维护（见上）。
- 不用 Matplotlib 独立弹窗：要做的是**软件界面**（按钮、选文件、状态栏），光弹一张图不够，必须有 GUI 框架托管。
- 不一次装全套依赖：阶段 1 只要 numpy + matplotlib（约 30MB）；PySide6 约 150MB，用到再装，出问题好定位。

## 4. 组会 30 秒话术（背下来）

> 技术栈我选的是 Python + PySide6 + Matplotlib + NumPy，最后用 PyInstaller 打包。界面层选 PySide6 而不是 PyQt5，主要三条：一是它是 Qt 官方维护的绑定，二是 LGPL 许可证允许我们闭源交付、没有法律风险，三是它和 PyQt5 的 API 基本一致、教程通用，也和团队 UAV 项目统一。绘图我用 Matplotlib，因为它能精细控制色表和 colorbar，又能嵌进 Qt 窗口，最接近老师要的 MATLAB 效果。
