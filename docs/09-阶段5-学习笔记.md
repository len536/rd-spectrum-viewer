## 1. PyInstaller 是什么 + 为什么（组会必问）

**PyInstaller = 把「你的代码 + Python 解释器 + 依赖库」塞进一个快递盒（exe）的工具。**

它做三件事：
1. **静态分析**你的代码，顺着 `import` 找出所有用到的库；
2. 把 Python 解释器、这些库、你的代码**一起收进包**；
3. 生成一个启动器（bootloader），双击时把包解开、运行你的程序。

**为什么必须打包**：老师电脑没装 Python。发 `.py` 没用，发 `.exe` 才能双击就跑。

### 两种模式（选型）

| 模式 | 输出 | 优点 | 缺点 | 本项目 |
|---|---|---|---|---|
| `--onedir` | 一个文件夹（exe + `_internal` 一堆 dll） | 启动快、排错容易 | 要整个文件夹一起发 | 调试时用 |
| `--onefile` | 单个 exe（76MB） | 好交付，发一个文件就行 | 每次启动先解压到临时目录，慢几秒 | ✅ **最终交付选它** |

类比：`onefile` 像一个**自热火锅**（所有东西打包在一起，带一个盒子走）；`onedir` 像**分装的食材盒**（一整箱，打开就能用但你得搬一箱）。

## 2. 打包命令逐参数拆解

最终命令（在仓库根目录执行）：

```bash
.venv\Scripts\python.exe -m PyInstaller --noconfirm --onefile --windowed \
  --name "RD谱图上位机" \
  --collect-data matplotlib \
  --paths 01_backend \
  --hidden-import rd_data \
  --hidden-import make_fake_rd \
  04_thread/rd_viewer_threaded.py
```

| 参数 | 字面 | 干嘛的 | 去掉会怎样 |
|---|---|---|---|
| `-m PyInstaller` | module | 用模块方式调用打包器（等价于直接调 `.venv\Scripts\pyinstaller.exe`） | — |
| `--noconfirm` | no + confirm | 输出已存在时直接覆盖，不弹确认 | 重打包时会卡在"是否覆盖"提示 |
| `--onefile` | one + file | 打成单个 exe | 默认 `--onedir`，出来一文件夹 |
| `--windowed` | windowed | 不弹黑色控制台窗口（GUI 软件必须） | 双击 exe 会先弹个黑框，不专业 |
| `--name` | 名字 | 指定 exe 文件名 | 默认用脚本名 |
| `--collect-data matplotlib` | collect + data | 把 matplotlib 的**数据文件**（字体配置、mpl-data）一起打包 | 打包后中文乱码 / 找不到字体 |
| `--paths 01_backend` | paths | 告诉 PyInstaller **额外去这个目录找模块** | ★ 找不到 `rd_data`（本次踩的坑，见第 3 节） |
| `--hidden-import rd_data` | hidden + import | 强制把静态分析"漏掉"的模块打进去 | ★ 同上，运行报 `ModuleNotFoundError` |
| `--hidden-import make_fake_rd` | 同上 | 兜底造数据函数也依赖它 | 换电脑无数据时造不出默认数据 |

> `--paths` 和 `--hidden-import` 常**一起用**：前者告诉去哪找，后者告诉必须带上。

## 3. ★ 踩坑实录：开发能跑，打包就崩（本阶段最值钱的知识点）

### 3.1 现象

第一次打包（只加 `--collect-data matplotlib`）看似成功，日志末尾有：
```
145159 INFO: Warnings written to ...\warn-RD_Spectrum_Viewer.txt
```
翻警告文件发现一行：
```
missing module named make_fake_rd - imported by rd_viewer_threaded.py
```

模拟换电脑（把 `data/` 移走）运行 exe，直接崩：
```
Traceback (most recent call last):
  File "rd_viewer_threaded.py", line 37, in <module>
ModuleNotFoundError: No module named 'rd_data'
```

### 3.2 原因（这是理解打包的关键）

主程序第 36-38 行是这样写的：

```python
sys.path.insert(0, str(ROOT / "01_backend"))   # 运行时才把后端目录加进搜索路径
from rd_data import load_rd
from make_fake_rd import make_fake_rd
```

PyInstaller 是**静态分析**——它读源码、看 `import` 语句，但**不执行代码**。
`sys.path.insert(...)` 是**运行时**才生效的动态路径设置，PyInstaller 分析时不知道 `01_backend` 这个目录存在，所以没把里面的 `rd_data.py` / `make_fake_rd.py` 收进包。

> 类比：打包器像图书管理员按书单（import）收书。你书单上写着"张三的书"，但没告诉他张三的书在哪个书架（`sys.path.insert` 是运行时才摆的书架）——他找不到，就没收。等你运行 exe 时去拿，书不在。

### 3.3 修法

在打包命令里显式补两句（见第 2 节）：
- `--paths 01_backend`：告诉打包器"去这个书架找"
- `--hidden-import rd_data --hidden-import make_fake_rd`：告诉它"这两本必须收"

这些配置会写进 `.spec` 文件的 `pathex=['01_backend']` 和 `hiddenimports=['rd_data', ...]`，以后改配置可以直接编辑 spec 再 `pyinstaller xxx.spec`。

### 3.4 验证修复生效

重新打包后，同样"移走 data 运行 exe"：
- 之前：抛 `ModuleNotFoundError`，秒退；
- 现在：无报错，进程一直跑到超时被杀（退出码 124）——说明事件循环正常在跑。

**这组对比就是"修复生效"的证据。** 记得这个判据：GUI 程序被 timeout 杀掉（124）= 它活着在正常跑；秒退 + traceback = 崩了。

打包产物（build*/dist*/*.spec/*.log/exe）全部 gitignore——**它们能从源码重建，不进仓库**。仓库里留的是源码 + 这份笔记；谁要 exe，照第 2 节命令打一份即可。

> ⚠️ **顺手踩的小坑（.gitignore 行内注释）**：最初写 `*.log   # 打包日志`，结果 log 文件没被忽略。原因是 **gitignore 不支持行内注释**——`#` 后面的空格和文字会被当成文件名的一部分。修法：注释必须**单独占一行**。这跟 Python 的 `x = 1  # 注释` 不一样，别套用。用 `git check-ignore -v 文件名` 能查某条规则到底生没生效。

## 5. 自测题（不看上面，能讲出来才算过）

1. PyInstaller 打包时把哪三样东西塞进 exe？为什么必须打包、不能直接发 .py？
2. `--onefile` 和 `--onedir` 各适用什么场景？本项目最终选哪个？
3. `--windowed` 去掉会怎样？`--collect-data matplotlib` 去掉会怎样？
4. ★ 为什么"开发能跑的程序，打包后会报 ModuleNotFoundError: rd_data"？`--paths` 和 `--hidden-import` 各解决什么？
5. 运行 exe 被 `timeout` 杀掉返回 124，和秒退 + traceback，分别说明什么？

<details>
<summary>答案（先自己答，再展开）</summary>

1. 你的代码 + Python 解释器 + 依赖库。老师电脑没装 Python 和这些库，发 .py 跑不起来，发 exe 才能双击就跑。
2. onefile = 单个 exe、好交付但启动慢几秒（解压），最终交付用它；onedir = 文件夹、启动快但要整箱发，调试排错用。本项目最终选 onefile。
3. 去掉 --windowed：双击 exe 会先弹黑色控制台框（不专业）。去掉 --collect-data matplotlib：matplotlib 的字体/配置数据没打包，中文乱码或后端报错。
4. 因为代码用 `sys.path.insert` 运行时才把 01_backend 加进搜索路径，而 PyInstaller 静态分析不执行代码、看不到这个动态路径，就没把 rd_data.py 收进包。`--paths 01_backend` 告诉它去哪找，`--hidden-import rd_data` 强制把漏掉的模块带上，两者配合使用。
5. 返回 124 = 进程一直活着直到被 timeout 杀，说明 GUI 事件循环正常在跑（成功）；秒退 + traceback = 程序启动就崩了（失败）。

</details>

## 6. 组会 30 秒话术（背下来）

> 最后我用 PyInstaller 把程序打成了 exe，解决老师电脑没装 Python 的问题。打包时遇到一个典型的坑：我的代码用 `sys.path.insert` 动态添加后端目录，而 PyInstaller 是静态分析、看不到这种运行时路径，导致 `rd_data` 模块没被打进去，exe 一运行就报 ModuleNotFoundError。我加了 `--paths` 指定搜索目录、`--hidden-import` 强制带上漏掉的模块，重新打包后验证通过。最终用 onefile 模式交付单个 76MB 的 exe，双击即可运行。
